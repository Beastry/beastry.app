常见问题

一酱免费吗？

是。MIT 开源，发行版在 GitHub 发布。

会上传截图到云端吗？

不会。捕获与可选本机模型均在本地运行，除非你自行配置外部接口。

一酱是谁？

Octoshot 的原创吉祥物——一只低能量、略嫌弃的红色卡通章鱼，造型来自应用图标。人设是「嘴上嫌弃、手上靠谱」：吐槽归吐槽，八只手同时干区域/窗口/全屏捕获、标注、滚动截屏、录屏/GIF、OCR/LaTeX、钉住等活。你的菜单栏截图管家。
